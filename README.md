# Coalition Missions Impact map

Live: **https://jessarnds-design.github.io/coalition-missions-map/**

A public map of missionaries and ministries that churches on the CoalitionCEC map publish on their own websites. Sending churches are shown in Northern California. Fields are plotted at country or broad-region level only.

## Security

- Initials, “classified,” “name withheld,” asterisks, and workers in closed regions (North Africa, the Middle East / MENA, Central Asia, and similar) appear only as **Name withheld for security — [region]**.
- No city-level pins for mission fields.
- Classified listings with no published region are noted on the sending-church pin, not placed on a guessed coordinate.

## Data

Built from `/workspace/coalition-missionaries/missionaries.csv` (173 published listings from 24 of 76 churches checked, about 161 unique missionaries or ministries). See `../coalition-missions/article.md` for the Article copy.

Tiles are OpenStreetMap (no API key). Branding uses Coalition forest green `#173027`, gold `#E7B65E`, and cream `#F6EFE0`.

Updated November 21, 2026 (America/Los_Angeles).
